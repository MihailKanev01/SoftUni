## Technology

- Java
- IntelliJ IDEA or another Java IDE

## How to Use

Clone the repository:

```bash
git clone https://github.com/MihailKanev01/SoftUni.git
cd SoftUni
```

Open the project in your preferred Java IDE, then navigate to the exercise folder you want to review. Individual folders contain independent practice solutions and may need to be run separately.

## Repository Purpose

This repository records coursework and practice. The exercises are learning artifacts and are kept separate from larger portfolio applications.
